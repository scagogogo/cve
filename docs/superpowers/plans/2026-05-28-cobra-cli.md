# Cobra CLI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: `superpowers:subagent-driven-development`
> Steps use checkbox (`- [ ]`) syntax.

**Goal:** 基于 Cobra 框架封装 CLI 命令行入口，将现有 19 个公共 API 函数暴露为子命令，支持管道输入和结构化输出

**Architecture:** 用户通过 CLI 参数/管道输入 CVE 文本 → Cobra 子命令解析参数 → 调用 cve 包对应函数 → 格式化输出到 stdout。关键组件：root.go（根命令+全局 flag）、6 个子命令文件（format/validate/extract/compare/filter/generate）、main.go（入口）。设计理由：复用现有 cve 包的纯函数，CLI 层仅做参数解析和输出格式化，零业务逻辑重复

**Tech Stack:** Go 1.18, Cobra v1.8.x, cve 包 v0.0.1

**Scope:** Medium

**Risk:** Low

**Risks:**
- Task 1 引入 cobra 外部依赖 → 缓解：cobra 是 Go 生态最成熟的 CLI 框架，CI 使用 `go mod download` 自动处理
- 管道输入可能遇到大文件 → 缓解：使用 `bufio.Scanner` 逐行读取，不一次性加载到内存
- go 1.18 兼容性 → 缓解：Cobra v1.8.x 支持 Go 1.18+

**Autonomy Level:** Full

```go
package cmd

import (
	"bufio"
	"os"
)

// readInputs reads CVE inputs from args or stdin.
// If args are provided, uses them directly.
// Otherwise, reads from stdin line by line.
func readInputs(args []string) []string {
	if len(args) > 0 {
		return args
	}

	stat, _ := os.Stdin.Stat()
	if (stat.Mode() & os.ModeCharDevice) != 0 {
		return nil
	}

	var lines []string
	scanner := bufio.NewScanner(os.Stdin)
	for scanner.Scan() {
		line := scanner.Text()
		if line != "" {
			lines = append(lines, line)
		}
	}
	return lines
}
```
